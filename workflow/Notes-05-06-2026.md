# Elements Card Battle Game
## Game Overview
This is meant to use the core principles of 2-paradoxical graph theory to produce a balanced but entertaining game; This is kinda like Rock Paper Scissors but with extra items and pairings.

Players will build their own set of Elemental Golems, each with their own Dominant and Passive Elements.

## Game Components
There are 3 Architypal Regimes, each with their own set of elements. Each element has a unique strength and weakness against other elements, creating a complex web of interactions.
| Architypal Regime | Elements                       |
|-------------------|--------------------------------|
| Stable            | Stone, Metal, Ice, Water       |
| Volatile          | Fire, Electric, Air, Nature    |
| Arcane            | Crystal, Void, Light           |

Each play will have a Dominant Element and a Passive Element; the Dominant Element is the one that is actively used in the battle, while the Passive Element provides support and can influence the outcome of the battle. Mixing and Matching Architypes will have certain outcomes based on the interactions of the Elements and Architype. The interactions are determined by a 2-paradoxical graph, where each Element and Architype has strengths and weaknesses against other elements.
